## 2. Weekly teaching brief

Use week 5 dates from the [teaching index](../course-plan.md#6-twelve-dated-teaching-weeks)
and the agreed [clock timetable](../course-plan.md#4-timetable-and-vocabulary).

- Question: Which copying mistakes can become useful evidence?
- Target: classify omissions, repetitions and substitutions with examples.
- Activity: start a new text branch from the week 1 card using a supplied
  branching assignment, not just one linear chain. Introduce controlled errors;
  retain the true parent log for the later reveal. Use an instructor fallback
  dataset if the class copies are not informative enough.
- Output: anonymised text witnesses and an error table for week 6. Students
  reconstruct another group's pack, not their own known chain.
- Check: classify two errors and explain why a common spelling correction may
  be weak evidence for ancestry.
- Candidate reading: Bernard Bischoff, *Latin Palaeography*, selected passage.
- Accessible route: editable text with line IDs; no unfamiliar-script skill is
  assessed. **The Chain due Friday 2027-03-26, 12:00 Canberra time.**

## 3. How the lecture and workshop run

### Monday lecture — 60 minutes

Explain omissions, repetitions and substitutions through short worked examples. Define any specialist terminology. Discuss why a common correction may arise independently; neither error counting nor classification is universally sufficient.

See the [shared lecture procedure](README.md#shared-teaching-and-page-procedure).

### Wednesday workshop — 120 minutes

**Investigation (40 minutes):** Follow the supplied branching instructions to produce text witnesses (20 minutes); classify differences with line IDs (10); package another group’s anonymised witnesses for reconstruction (10). Reuse the controlled instructor pack as the fallback.

Use the workshop stages and quiz rubric from the
[shared procedure](README.md#shared-teaching-and-page-procedure).
