## 1. Purpose and progression

**Distinct capability:** Select a feature that supports inheritance under stated assumptions.

**Archive placement:** Audio. Apply week 1 measurement discipline; start a separate audio family. Preserve the source record for week 3; retain the recording if producing actual audio. Week 6 can compare this pairwise inference with a full text tree.

## 2. Weekly teaching brief

Use week 2 dates from the [teaching index](../course-plan.md#6-twelve-dated-teaching-weeks)
and the agreed [clock timetable](../course-plan.md#4-timetable-and-vocabulary).

- Question: Which shared features are useful evidence of a common intermediate copy?
- Target: distinguish a branch-specific inherited feature from one found in the
  source or introduced independently by a common process.
- Lecture emphasis: compare three explanations for a shared feature—present in
  the source, inherited from an intermediate, or introduced separately. Use a
  worked pairwise comparison; reserve full tree reconstruction for week 6.
- Supplied evidence: an on-page source-plus-four-copy feature table with timings
  and a construction log for the reveal. Include a local feature inherited by
  two copies and a general noise feature across branches. Label an authored
  scenario as hypothetical; do not claim these are measured cassette results.
  Parent identities appear only in the answer reveal. Audio clips and aligned
  waveforms are optional extensions, not prerequisites for this inference task.
- Investigate (40 minutes): locate and tabulate features (10); compare their
  presence in the source and four copies (15); select evidence for one proposed
  sibling pair and test an alternative explanation (15). Use consistently
  prepared comparison files and disclose any alignment or level normalisation.
- Output: evidence table with feature location, affected copies, proposed
  explanation and confidence. Add one supported relationship to the audio
  archive; use week 1's measurement discipline and retain the source for week 3.
- Check: from a fresh supplied feature table, choose whether a local dropout or
  general hiss better supports a proposed pair and explain why. Feedback should
  show that a branch-specific event can be more informative under the pack's
  assumptions, while still allowing independent introduction as an alternative.
- Candidate reading: Peter Manuel, *Cassette Culture*, selected context passage;
  add a verified technical reference for any measurement procedure taught.
- Accessible route: aligned feature tables and labelled waveforms provide the
  same evidence without listening. Assessment link: practise LO3 reasoning for
  The Stemma and choose a relevant observation for The Chain.
- Before publishing: rehearse the pack and confirm the selected feature supports
  the intended relationship under its declared assumptions. The answer must not
  depend on superior hearing or an unexplained hidden fact.

## 3. How the lecture and workshop run

### Monday lecture — 60 minutes

Compare source features, inherited intermediate features and independently introduced effects. Demonstrate a pairwise evidence table; keep music-history context brief and supported. Full tree construction belongs in week 6.

See the [shared lecture procedure](README.md#shared-teaching-and-page-procedure).

### Wednesday workshop — 120 minutes

**Investigation (40 minutes):** Use the three-part 40-minute investigation specified in §2 above; retain its feature-selection task and alternative explanation.

Use the workshop stages and quiz rubric from the
[shared procedure](README.md#shared-teaching-and-page-procedure).
