## 1. Purpose and progression

**Distinct capability:** Define and apply a reproducible measure before drawing a conclusion.

**Archive placement:** Print. Create the print family. Week 2 reuses the measurement discipline, not the print page as an audio ancestor. Week 5 works on a second print document, the Ordinance, which students have not seen. The print collection holds both: a legibility test card built from confusable glyphs for counting, and a prose text for scribal error. Reusing one document would let a student reconstruct week 6 from memory instead of from evidence.

## 2. Weekly teaching brief

Use week 1 dates from the [teaching index](../course-plan.md#6-twelve-dated-teaching-weeks)
and the agreed [clock timetable](../course-plan.md#4-timetable-and-vocabulary).

- Question: How can we measure a copy becoming harder to read?
- Target: define a repeatable measurement and explain disagreement between readers.
- Activity: compare three supplied print-copy examples with the original; optionally
  make a new chain. Use the same transcription task and settings across copies.
  Include an exact digital-copy control to challenge the universal-loss claim.
- Output: character-error table, method and observation about uncertainty;
  establish the print family and the measurement template reused in week 2.
- Five-minute check: compare two copies, cite one observed difference and name
  something that cannot establish their generation order. Indicative feedback:
  worse legibility can support an ordering under controlled conditions but is
  not an independent timestamp.
- Candidate reading: David Owen, *Copies in Seconds*, a selected passage.
- Assessment: introduce The Chain and the prediction record; walk through a
  completed miniature example. Accessible route: supplied transcriptions with
  marked differences; no grading of eyesight.

## 3. How the lecture and workshop run

### Monday lecture — 60 minutes

Use a print comparison to introduce measurement. Work through a character-error table and an exact digital-copy control; explain why readers can disagree and why that does not make every property purely subjective.

See the [shared lecture procedure](README.md#shared-teaching-and-page-procedure).

### Wednesday workshop — 120 minutes

**Investigation (40 minutes):** Transcribe selected supplied copies (10 minutes); calculate errors against the source using a common rule (15); compare readers and the exact-copy control (15). Physical copying is optional.

Use the workshop stages and quiz rubric from the
[shared procedure](README.md#shared-teaching-and-page-procedure).
