Observation tolerance — a scenario rule
Authored teaching scenario. Every observation, prediction and evidence record below was written for this exercise. None was produced by running image software, and nothing here supports a claim about how any real tool or forensic technique behaves.

File size: within 15 KB.
width, height, chromaSubsampling, exif: must match exactly.

A scenario rule, not an empirically validated forensic tolerance. It is set for this exercise so that you can apply a stated threshold consistently. Two predictions that fall inside 15 KB of each other are indistinguishable on file size — meaning this evidence cannot separate them, not that the files are identical.
